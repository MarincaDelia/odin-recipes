# odin-recipes
A basic recipe website built as part of The Odin Project's Foundations course,
It has a homepage that links to several recipe pages.

#Skills practiced
-Structuring HTML documents with the standard boilerplate
-Using headings, paragraphs, and ordered/unorered lists
-Linking pages with relative links and adding images
-Using Git and GitHub( clone, add, commit, push)
